Key travel drives a virtual Xbox controller, so a half-pressed key gives a half-deflected stick. Needs ViGEmBus. No setting on the keyboard changes.
Bindings live in —. Creating them reads the key matrix and maps W, A, S and D to the left stick.

Write safety check

Confirms that decoding and re-encoding the key table reproduces the keyboard's own bytes exactly, so a write changes only the field it targets. Read-only.

Debug flag

A firmware flag in the keyboard's settings. Analog travel works without it, so leave it off unless you are investigating firmware behaviour.
